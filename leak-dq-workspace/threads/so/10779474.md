## Answer 10779860

responder · user149341 · 2012-05-28T05:46:40Z · score 3 · https://stackoverflow.com/a/10779860

While you should not write code which depends on this, pointers under 0x1000 are almost always invalid. Familiarity with the default memory map of your operating system will explain why, as well as give you some more insight into what "normal" pointers look like.

In general, it's very hard to say if a pointer is invalid or not, as e.g. `0xd8` is a valid address on some systems. The only invalid address you can be sure of is `NULL` (i.e. zero).
