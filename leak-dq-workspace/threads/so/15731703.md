responder · Daniel Fischer · 2013-03-31T17:58:19Z · score 0 · https://stackoverflow.com/questions/15731703/#comment22351797_15731703

Well, without initialisation, the contents are indeterminate, so whether that passes a null pointer to `realloc` is a toss-up. The first time, you are likely to get fresh memory zeroed out by the OS, and usually all bits 0 is a null pointer representation. Subsequent times, it's more likely to contain non-null junk.
