## Answer 23605263 [ACCEPTED]

responder · Alexander · 2014-05-12T09:20:14Z · score 1 · https://stackoverflow.com/a/23605263

Do like this with repdect to your functions:

```
JNIEXPORT void JNICALL Java_ClassName_MethodName
  (JNIEnv *env, jobject obj, jstring javaString)
{

    const char *nativeString = (*env)->GetStringUTFChars(env, javaString, 0);

    (*env)->ReleaseStringUTFChars(env, javaString, nativeString);
}

```

The thing is to use `*env`

See C-example here
[http://en.wikipedia.org/wiki/Java_Native_Interface](http://en.wikipedia.org/wiki/Java_Native_Interface)
