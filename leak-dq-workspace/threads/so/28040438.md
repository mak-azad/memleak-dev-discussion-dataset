## Answer 28040485

responder · Gopi · 2015-01-20T08:16:37Z · score 0 · https://stackoverflow.com/a/28040485

Memory leak can easily be produced

```
void func()
{
  int *ptr = malloc(sizeof(int) * 1000);
  return;
}

```

You are not freeing the memory allocated to the pointer `ptr` and hence there is a memory leak because this allocated memory is not available for other applications and eventually if you keep doing this then you run out of memory.Like

```
while(1)
{
   int *ptr = malloc(sizeof(int) * 1000);
}

```

## Answer 28040709

# ee.c

```
#include<stdio.h>
#include<stdlib.h>
#include<unistd.h>

 int main( void )
{
    int *ptr = NULL;

    while ( 1 )
    {
        ptr = (int*) malloc ( 1024 );
        sleep ( 2 );
    }
    return ( 0 );
}

```

1. gcc -o memory ee.c

# mem_leak.sh

```
#!/bin/bash
echo " memory leak script started"
./memory

```

1. chmod 777 mem_leak.sh

1. ./mem_leak.sh
