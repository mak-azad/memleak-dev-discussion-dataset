## Answer 31333174

responder · 6502 · 2015-07-10T05:33:03Z · score 5 · https://stackoverflow.com/a/31333174

`delete` must be used only for objects that have been allocated on the heap with `new`.

In your code all the 4 nodes have been allocated on the stack so calling `delete` on them is an invalid operation that leads to "undefined behavior".
