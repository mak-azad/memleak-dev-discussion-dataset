## Answer 35879988

responder · chqrlie · 2016-03-08T23:17:49Z · score 0 · https://stackoverflow.com/a/35879988

`vertexloop` is allocated by a custom function this way:

```
vertexloop = (vertex) poolalloc(&m->vertices);

```

You should test if `vertexloop` is `NULL` and abort with a meaningful message.

If this tells you that memory cannot be allocated, investigate `poolalloc` to see if there are any limitations that cause allocation failure on a gigantic machine, these limitations could be imposed by the OS via a quota. Write a simple allocation test with `malloc` and see when it fails.
