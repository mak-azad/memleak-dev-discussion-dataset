I had a similar question like your first one. To answer (most of) your questions:

1. 

I just experimented with X509_STORE_add_cert() since I could not find documentation of its behavior w.r.t. the cert referenced. The function increments the reference count of the cert added. So you should free the cert when you don't need it any more for other purposes.

1. 

and 3.) SSL_CTX_free() does free the referenced X509_STORE if its reference count becomes 0, which will in turn (indirectly) call X509_free(). Since this will release the memory allocated for the cert only if its reference count becomes 0, you need to free your reference to the cert as well.

1. 

and 4.) You should not try to directly use the reference counter nor need to worry about it. Whoever allocates an object or adds a reference to it is responsible for freeing it (once).
