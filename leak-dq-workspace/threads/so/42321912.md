## Question

I'm not sure that the destructor is actually getting called. I'm using a priority_queue to hold a bunch of nodes. Each node has a member, m_grid, that is a 2D array of structs. This grid represents the only pointers I explicitly use in my program. 

For some reason, I'm getting lots of leaks. Could you help me out?

Here's the destructor:

```
grid::~grid()
{
  for (int i = 0; i < m_width; i++)
  {
    delete[] m_grid[i];
    m_grid[i] = NULL;
  }

  delete[] m_grid;
  m_grid = NULL;
}

```

The assignment operator:

```
grid& grid::operator=(const grid& g)
{
  m_x_rad = g.m_x_rad;
  m_y_rad = g.m_y_rad;
  m_width = g.m_width;
  m_height = g.m_height;
  m_orientation = g.m_orientation;

  if (m_width != 0)
    m_grid = new cell* [m_width];

  // from left to right
  for (int i = 0; i < m_width; i++)
  {
    m_grid[i] = new cell [m_height];

    // from top to bottom
    for (int j = 0; j < m_height; j++)
    {
      m_grid[i][j].m_occupied = g.m_grid[i][j].m_occupied;
      m_grid[i][j].m_rad = g.m_grid[i][j].m_rad;
    }
  }

  return *this;
}

```

## Answer 42321948

responder · Lightness Races in Orbit · 2017-02-18T23:42:30Z · score 0 · https://stackoverflow.com/a/42321948

A call to the assignment operator doesn't automatically call the destructor first. You have to cleanup any memory already owned by the object, yourself, if you're going to replace it with new memory.

Assignment doesn't make a new object; it just modifies the object you've already got.
