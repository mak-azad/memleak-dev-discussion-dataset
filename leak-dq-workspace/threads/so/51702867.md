## Comment on question 51702867 90396723

responder · user3629249 · 2018-08-07T02:14:27Z · score 0 · https://stackoverflow.com/questions/51702867/#comment90396723_51702867

regarding: `str = (char*)malloc(sizeof(char) * (size + 1));` 1) the expression: `sizeof(char)` is defined in the C standard as 1.  Multiplying anything by 1 has absolutely no effect.  Suggest removing that expression.  2) the returned type from the heap allocation functions: `malloc` `calloc` `realloc` is `void*` which can be assigned to any pointer.  Casting the returned value just clutters the code, making it more difficult to understand, debug, etc. Suggest removing that cast.

## Comment on question 51702867 90396757

responder · user3629249 · 2018-08-07T02:16:58Z · score 0 · https://stackoverflow.com/questions/51702867/#comment90396757_51702867

regarding: `if (str == NULL)         return (str);`  When the call to `malloc()` fails, a NULL pointer is returned to `main()`.  `main()` starts writing to that pointer.  When `malloc()` fails, this will result in a seg fault event.  Suggest using: `if (str == NULL) {  perror( "malloc failed" );  exit( EXIT_FAILURE ); }`
