## Answer 5226756

responder · samplebias · 2011-03-07T23:48:48Z · score 6 · https://stackoverflow.com/a/5226756

You may need to use a [valgrind suppressions file for Mac](https://github.com/svn2github/valgrind/blob/master/darwin9.supp). Looks like some process-wide memory is allocated by not freed when the process exits. Try with `valgrind --suppressions=<path to suppression file>`.
