## Answer 5322889

responder · Benoit Thiery · 2011-03-16T08:53:31Z · score 4 · https://stackoverflow.com/a/5322889

This is normal behaviour. The memory will be reused if you do some other allocations in your process, but it is not returned as free memory to the OS for performance reasons.
You don't have a memory leak as this memory is not lost, but it can only be reused by your process (until it exits of course).
