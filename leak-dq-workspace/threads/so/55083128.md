## Answer 55083200

responder · Ajay P · 2019-03-10T00:02:23Z · score 0 · https://stackoverflow.com/a/55083200

There is no problem in link list creation. However, once you are done with reading file and link list you need to free up. Remember if you used malloc(), you have to call free() to free up the memory. Something like this - freeCellule(), you can call this function before returning from lectureFichier():

```
   void freeCellule(message *ptr)
   {
       message * next;
       while (ptr) {
           next = ptr->suivant;
           free(ptr);
           ptr = next;

      }
   }

```
