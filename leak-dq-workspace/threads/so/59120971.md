## Comment on question 59120971 104471932

regarding: `ainputStr = malloc( (i+1)*sizeof(char) );`   1) this will not work to update the value in function: `main()` as the address of the variable in `main()` was not passed.  2) in C, the expression: `sizeof(char)` is defined as 1,  Multiplying anything by 1 has no effect.  Suggest removing that expression.  3) Suggest removing the `ainputStr` parameter.  4) when calling `malloc()`, always check (!=NULL) the returned value to assure the operation was successful.  5)  Suggest: `char * ainputStr = malloc( i+1); if( !ainputStr ) { perror( "malloc failed" ); exit( EXIT_FAILURE ); }`
