## Answer 60872632

responder · Paul Ogilvie · 2020-03-26T17:13:54Z · score 0 · https://stackoverflow.com/a/60872632

Your loops are wrong:

```
for (i = 0; i<A ; i++ ){
   if (Temp_Key1[i] < Temp_Key1[i+1]){

```

but for `i` is `A-1`, there is no `Temp_Key1[i+1]`, i.e, there is no `Temp_Key1[A`].

The same for your loop

```
for ( i = A ; i >= 0 ; i--){
    node->value = Temp_Val[i];

```

there is no `Temp_Val[A]`.

Just change to

```
for (i = 0; i<A-1 ; i++ ){

```

and

```
for ( i = A-1; i >= 0 ; i--){

```
