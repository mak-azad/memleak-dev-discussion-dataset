## Question

Im trying to free the `char* line` before closing the method to avoid having memory allocated in the heap for something that only serves a local purpose every time the method is called. When calling the free() method for the `char* line` im getting this error: `free(): invalid pointer`

Im still a beginner developer and im still learning the memory allocation concepts of C, it would be great if someone could explain me why my pointer is no longer valid to be freed up ( im guessing it has something to do with `strtok()`)

In `line = strtok(line, " ");` and `line = strtok(NULL," ");` you've lost the pointer from the `malloc()` allocation. Save it in another variable - you can only pass a pointer to `free()` that came from `malloc` - not somewhere within the memory block.

Do this: `char *lptr = malloc(256); char *line = lptr; .... free(lptr);` You need to set `line = lptr` in *every* loop iteration. Otherwise the next `fgets()` will overflow the buffer :)
