The loop `for(int i = 0; i <= 3; ++i)` creates **4** nodes, but the sanitizer only reports **3** allocations. Note that the `free()` is not strictly necessary because dynamically allocated memory is handed back to the system on program exit, but it's good practice to do the housekeeping yourself.

## Comment on question 65280097 115409084

responder · Weather Vane · 2020-12-13T20:58:49Z · score 0 · https://stackoverflow.com/questions/65280097/#comment115409084_65280097

`malloc()` is fine for this job. To free the linked list, traverse it until you reach the `NULL` pointer link, putting each `next` member into a temporary variable and `free()` the node memory. You need the temporary variable because the `next` link won't be accessible after you `free()` the node. Practice the traversal with a `printlist()` function first.
