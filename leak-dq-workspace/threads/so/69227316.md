## Comment on question 69227316 122362630

responder · Nate Eldredge · 2021-09-17T23:35:29Z · score 0 · https://stackoverflow.com/questions/69227316/#comment122362630_69227316

`FREE` is [a function-like macro](https://github.com/NCAR/ncl/blob/83ea393b25e15bd850c034c364edc25c0257702b/ni/src/nyacc/defs.h#L102) that just calls `free`, but you might as well use it for consistency.  But like a function, it needs a semicolon at the end of the statement, which you have omitted.  It's unclear if that is the cause of your error; if so there would have been more specific compilation errors further up, that maybe you left out.

## Comment on question 69227316 122362637

responder · Nate Eldredge · 2021-09-17T23:36:59Z · score 0 · https://stackoverflow.com/questions/69227316/#comment122362637_69227316

Putting the `FREE(a_line);` at the end of the function won't fix the leak, though, because `copy_action` has `return;` statements at several other places.  You need to make sure that `a_line` gets freed no matter which one of them is taken.  In fact it looks to me like putting it at the end is completely unreachable; every branch of the preceding `switch` ends with either `return` or `goto` (ugh ugh ugh) but never `break`.
