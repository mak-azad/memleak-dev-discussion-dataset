Your problem is here

```
void Insert(int x){
    struct Node* temp = (struct Node*)malloc(sizeof(struct Node));
    struct Node* ptr = head;
    
    //check if already present
    while(ptr != NULL){
        if(ptr->data == x){return;}  <--- If this return is executed, temp is not freed
        ptr = ptr->next;
    }

```

To fix it just move the `malloc` so it's after the loop.

```
void Insert(int x){
    struct Node* ptr = head;
    
    //check if already present
    while(ptr != NULL){
        if(ptr->data == x){return;}
        ptr = ptr->next;
    }

    struct Node* temp = malloc(sizeof(struct Node));

```

BTW:

1. 

Having `head` as a global variable is a bad idea

1. 

Don't cast the value returned by `malloc`
