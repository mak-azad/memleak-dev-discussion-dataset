## Answer 6973510 [ACCEPTED]

responder · Alok Save · 2011-08-07T14:52:54Z · score 17 · https://stackoverflow.com/a/6973510

`Still reachable` is **not a memory leak.**  

`Still reachable` means that a block of memory has not been freed but there are still valid pointers to the start of that block in registers or memory that has not been freed.

You need to have a look at **[the Valgrind FAQ](http://valgrind.org/docs/manual/faq.html#faq.reports)**. The actual reason for `libgomp` causing the warning is explained **[here](https://gcc.gnu.org/bugzilla/show_bug.cgi?id=36298)**.
