When you destroy the window, you effectively release the underlying OpenGL context, thus the GL resources (including the shaders you created) will be freed. What you want to do is have a shared openGL context that you pass to glfwCreateWindow as the last argument that is shared among all the Form instances you create.

You want to make sure to keep the original form window around so that its opengl resources are not deallocated (which causes your current issues).

```
GLFWwindow * orig_window = glfwCreateWindow(800, 600, "The original window", NULL, NULL);
//init shaders etc. that you want to share between windows...

//for all windows created later, pass the original window as a shared context
GLFWwindow * shared_window = glfwCreateWindow(800, 600, "A shared window", NULL, orig_window);

```

For more info, check out the GLFW reference here: [https://www.glfw.org/docs/3.3/group__window.html#ga5c336fddf2cbb5b92f65f10fb6043344](https://www.glfw.org/docs/3.3/group__window.html#ga5c336fddf2cbb5b92f65f10fb6043344)
