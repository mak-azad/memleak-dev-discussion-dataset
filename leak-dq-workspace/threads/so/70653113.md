## Question

See this demo:

```
#include <malloc.h>
#include <stdio.h>
#include <stdlib.h>

void Pause() {
    int v; {
        scanf("%d", &v);
    }
}

int main(int argc, char **argv) {
    Pause();
    printf("Hello.\n");
    malloc_trim(0);
    Pause();
    return 0;
}

```

mem status at the first `pause()`:

```
root     1288815  0.0  0.0  15616   844 pts/1    S+   21:13   0:00 ./a.out

```

mem status at the second `pause()`:

```
root     1288815  0.0  0.0  15620   844 pts/1    S+   21:13   0:00 ./a.out

```

I used `malloc_trim(0)` to make sure the released memory has been returned to OS, then I used pmap and found that the program allocated a page of memory on heap and won't be released. What is it?  

I'm using centos.

The output buffer must be retained between calls to `printf`, because it is discharged either a) when full, b) when `'\n'` is output, c) with `fflush(stdout)`.
