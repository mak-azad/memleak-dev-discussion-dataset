I think you are incorrectly mixing `int[][]` and `int **`. For example, you cannot pass `&A` to `MPI_Scatterv()`, and you must pass the address of the first element of the `A` array. `printf("%p\n", &A[0]0])` in your `main()` function, and double check this is what you pass to `MPI_Scatterv()`

Basically as @GillesGouaillardet says: remove the ampersands from the buffers in the MPI calls. An array == pointer == buffer. Also, an `int[][]` is an `int*`, not `int**` so some of your parameter passing is wrong too.

On my workstation, this problem is caused by the stack limits. Just ulimit it.

modify /etc/security/limits.conf

add:

"* soft stack unlimited"

"* hard stack unlimited"

modify /etc/pam.d/login

add:

session    required     /usr/lib64/security/pam_limits.so

Then,
Restart ssh
