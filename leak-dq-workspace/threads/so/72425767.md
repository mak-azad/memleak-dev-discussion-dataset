Don't you get an hs_err file/JVM crash log? It seems like maybe the native code, or something else, is installing it's own signal handler, which interferes with JVM features such as implicit null checking. You might try running with `-XX:-ImplicitNullChecks`. But, in general, signal handlers can interfere with the normal functioning of the JVM.
