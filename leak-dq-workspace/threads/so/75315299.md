Note: `ft_strcat(str, (char *)s2);` is a [Schlemiel the Painter's Algorithm](https://en.wikichip.org/wiki/schlemiel_the_painter%27s_algorithm). Instead, save the result from `ft_strlen((char *)s2)` into `x` and use it here: `ft_strcat(str + x, (char *)s2);`.
