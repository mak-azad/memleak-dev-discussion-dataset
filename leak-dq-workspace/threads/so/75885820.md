## Question

I wrote a function that will handle free of memory in linked list but the function was able to free them but i was getting memory leak. Please could someone tell me why this function was able to free my memory but there is memory leak.

```
void free_listint(listint_t *head)
{
    listint_t *temp;
     
    temp = head;
    while (head != NULL)
    {
         free(head);
         temp = temp->next;
    }
    return;
}

```

`while (head != NULL)`? Where inside the loop do you make `head` point somewhere else? You have an infinite loop, and the list will run out, and you will dereference the null pointer. That leads to *undefined behavior* and a likely crash.

## Answer 75885895

responder · Karthick · 2023-03-30T08:38:09Z · score 3 · https://stackoverflow.com/a/75885895

Your while loop checks for head but head is never reassigned inside the loop. This might cause infinite loop and `temp = temp->next;` might eventually crash.

I would suggest to rewrite like

```
void free_listint(listint_t *head)
{
    listint_t *temp;
     
    while (head != NULL)
    {
         temp = head->next;
         free(head);
         head = temp;
    }
    return;
}

```

@Karthick shows the OP's error and one solution. (credit!)

For the fun of it, the following may *scan* slightly easier:

```
void free_listint( listint_t *head )
{
    while( head )
    {
        // strive to limit the scope of variables
        listint_t *del = head;
        head = head->next;
        free( del );
    }
    // return; // this is unnecessary. write less code.
}

```
