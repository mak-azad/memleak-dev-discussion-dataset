The implementation of unload() should be

```
void unload(void) {
    for(int i = 0; i < N; i++) {
        node *cursor = table[i];
        while (cursor != NULL) {
            node *tmp = cursor;
            cursor = cursor->next;
            free(tmp);
        }
    }
 }

```

1. The function should return nothing instead of bool according to your logic.

1. The return inside of while loop terminate the for loop in its first iteration. Then the elements[1...n - 1] of table aren't freed, causing the memory leak.

OT Hint: When adding words (from a dictionary presumed to be sorted), the first word in any *chain* at a given hash value will be the "largest value" word in the list... When searching along that linked list for, for example, "dogg", you can stop the search (not found) when you encounter "cat" (or whatever word would *preceed* the absent "dogg". No need to keep comparing against "bat" and "aardvark"...
