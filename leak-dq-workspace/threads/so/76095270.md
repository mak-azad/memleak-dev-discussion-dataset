`sizeof(char)` is by definition 1. `malloc()` and `realloc()` each return a pointer-to-`void` which can (and should) be assigned to a variable of *any* pointer type without casting; and you should test such return-values against `NULL` before you dereference them. Also, since it's possible for `realloc()` to fail you should test its return-value against `NULL` *before* you throw away the old value.

You posted your assignment and a snippet of code which has issues:

1. You should point out that "unlimited" in the problem description is flawed.  You are limited by virtual memory or at least disk size.  Also sets, by definition are unsorted, so they should call it something else.

1. header files are missing

1. snippet of code not even in a function

1. `setSize` is not defined

1. `DEFAULT` is not defined

1. `inputN;` doesn't do anything; supposed to be an initialization?

1. `input` should be an `int` when used to store data from `getchar()`.

1. Not sure why you are dynamically allocating `input()` when it's a fixed array of size 2 (and really you just need an `int`).

1. `input == ' '` compares a pointer to an integer constant which is not what you want.

1. Assign the value from `realloc()` to a temporary variable, otherwise you leak memory on failure.  In the code below caller should handle a NULL return value.

1. Don't cast `void *`.

1. Prefer initializing variables when you declare them.  It's less duplication and you eliminate the error case of using an uninitialized variable.

1. Prefer to minimize scope of variables

1. Use more functions to structure your code.  For instance, if you can't use `scanf()` in this assignment, you now know that you just need to write your own implementation of reading an integer from `stdin`.  This function may fail.

```
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>

struct set {
    int *data;
    size_t n;
};

struct set *set_add(struct set *s, int v) {
    for(size_t i = 0; i < s->n; i++)
        if(s->data[i] == v)
            return s;
    int *tmp = realloc(s->data, sizeof(s->data) * (s->n + 1));
    if(!tmp)
        return NULL;
    s->data = tmp;
    s->data[s->n++] = v;
    return s;
}

void set_print(const struct set *s) {
    for(size_t i = 0; i < s->n; i++) {
        printf("%d%s", s->data[i], i + 1 == s->n ? "\n" : " ");
    }
}

struct set *set_get(struct set *s) {
    for(;;) {
        int v;
        if(scanf("%d", &v) != 1)
            break;
        set_add(s, v);
    }
    return s;
}

int main() {
    struct set *s = &(struct set) { 0 };
    set_get(s);
    set_print(s);
}
```
