Python 3.10
Pandas 1.5.2

The same versions are installed on MAC and Linux.

I'm developing in Python on MAC, but running the code on my Linux Ubuntu server. There seems to be a difference in memory usage, which is causing the memory load in Ubuntu to quickly reach its max and kill the process.

I noticed the Pandas library to cause significant amounts of leakage, so I created the following snippet to illustrate the problem:

```
import pandas as pd
import numpy as np
import psutil
import sys
import ctypes

# Set the number of repetitions
n                   = 100000
memory_check        = 0
memory_check_prev   = 0

# Create an empty list to store the correlation values
correlation_values = []

# Create a dataframe with random float numbers
df = pd.DataFrame(np.random.rand(3600, 2), columns=['Column1', 'Column2'])

# Perform the correlation calculation for each repetition
for _ in range(n):

    ### Correlation
    correlation     = df['Column1'].corr(df['Column2'])
    ### Percentual Change
    # df['returns']   = df['Column1'].pct_change()
    ### Filter dataframe based on idx values
    # df2             = df.loc[200:500]
    ### Filter dataframe based on str idx
    # df2             = df.loc[str(200):str(500)]

    # Malloc Trim
    if sys.platform.startswith('linux'):
        malloc_lib = ctypes.CDLL('/usr/lib/x86_64-linux-gnu/libc.so.6')
    else:
        malloc_lib = ctypes.CDLL('/Users/koen/libcustommalloc.dylib')
    malloc_lib.malloc_trim.argtypes = [ctypes.c_size_t]
    malloc_lib.malloc_trim.restype  = None
    malloc_lib.malloc_trim(0)

    # memory checks
    memory_check    = psutil.Process().memory_info().rss / 1000000000
    if memory_check != memory_check_prev:
        print('New total memory load: ' + str(memory_check))
        memory_check_prev = memory_check

```

As for the malloc_lib file >> On linux, the path above should work by itself. On MAC, a .dylib file needs to be created with the following code:

```
#include <stdio.h>
#include <stdlib.h>
#include <malloc/malloc.h>

void malloc_trim(size_t pad) {
    malloc_zone_t *zone = malloc_default_zone();
    malloc_zone_pressure_relief(zone, pad);
}

```

After creating this file, adjust the path in the Python code above to where you stored it.
