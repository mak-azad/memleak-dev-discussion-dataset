## Comment on question 76808559 135409197

responder · user17592432 · 2023-08-01T05:51:45Z · score 1 · https://stackoverflow.com/questions/76808559/#comment135409197_76808559

Hint: This line: `if (index > N) { return N - 1; }` will likely *populate* the last element of the hashtable with an unreasonably large number of nodes. Consider using `modulo` (ie: `return index % N` instead. This might build a word chain from `arr[0]` but won't try to populate the nonexistent `arr[N]`. And, it will 'distribute' "high value hashes" so the blind search to the end for misspelled words searches shorter chains...
