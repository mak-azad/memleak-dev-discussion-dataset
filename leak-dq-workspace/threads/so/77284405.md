## Comment on question 77284405 136250207

responder · Lundin · 2023-10-13T07:34:56Z · score 0 · https://stackoverflow.com/questions/77284405/#comment136250207_77284405

You *can* actually use qsort to sort a linked list, but then the linked list needs to be implemented by using an array or memory pool for data storage and not allocate nodes with separate calls to malloc. Which shouldn't be done anyway on "modern" (> year 1990) computers since it is is horribly inefficient. Those algorithm classes that taught you to use linked lists for fast inserting in the middle were wrong - inserting an item by moving an array of adjacent items one item to the side is likely *way* more efficient on a CPU with a bit of data cache memory, vs individual heap allocations.
