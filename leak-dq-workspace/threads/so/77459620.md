    cout<<"address cl2 points to:  "<<cl2.get()<<endl;
    cout<<"count reference of cl2: "<<cl2.use_count()<<endl;
    // cl2 is deleted after exit of this function
}

int main()
{
    cout<<"Size of MyClass "<<sizeof(MyClass)<<endl;

    cout<<"**init cl2**"<<endl;
    shared_ptr<MyClass> cl1 = make_shared<MyClass>();

}

With `cl1->next = cl2` you create a *copy* of the smart-pointer object. When the life-time of the variable `cl2` ends, the copy still lives, and points to the very same memory. If you check `cl1->next.use_count()` when back in the `main` function, you should notice that it's `1`.

That's kind of the point of a *shared ownership* structure like `std::shared_ptr`. You can have multiple owners to a single resource, and if one owner releases its ownership (like when `cl2` is destructed) the resource still lives on because there are other owners.
