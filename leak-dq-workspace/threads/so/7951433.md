```
struct s_ptx
{
    short       streamIndex;

    char        rawDx;

}  *Ptx[100];

void allocateMemory(void)
{
    ptxTotal = 300;

    for (int i = 0; i < 100; ++i)

void shiftDataStructures(void)

    for (int j = 100 - 1; j > 0; --j)
```

But I get wrong results, because the shiftDataStructures function is not working.  Any ideas of how I need to rewrite this.

responder · Ambroz Bizjak · 2011-10-31T12:55:23Z · score 0 · https://stackoverflow.com/questions/7951433/#comment9722492_7951433

Hope you're aware you're shifting the pointers one right, not one left. E.g. if you had pointers (0, 1, 2, 3) your loop will produce (0, 0, 1, 2). To shift one left: for (int i = 0; i < 100 - 1; i++) { Ptx[i] = Ptx[i + 1]; }. This will map (0, 1, 2, 3) to (1, 2, 3, 3).
