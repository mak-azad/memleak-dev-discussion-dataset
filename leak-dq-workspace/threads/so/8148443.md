responder · Ram · 2011-11-16T08:29:00Z · score 3 · https://stackoverflow.com/a/8148676

raw_image is a pointer to a character array of size imagewidth * imageheight *3. The '3' represents the three components in RGB triplet.

Looking at the code, what i understand is, the jpeg image is taken and read in to a buffer, which is sent to a processor which decompresses the image. further, the decompressed pixel data is written in to the raw_image buffer. The below code does this job by writing line by line. Hence the condition "cinfo.output_scanline < cinfo.image_height" and in for loop "i

```
while( cinfo.output_scanline < cinfo.image_height )
{
    jpeg_read_scanlines( &cinfo, row_pointer, 1 );
    for( i=0; i<cinfo.image_width*cinfo.num_components;i++) 
        raw_image[location++] = row_pointer[0][i];
}

```

Before writing out this raw_image buffer in to a file, i suppose you want to make some post processing. is that right? If it is so... You can access the pixels in this way.

```
for (i=0; i < cinfo.image_height; i++){
 for (j=0; j < cinfo.image_width; j++){
   // Pixel (i,j)
   raw_image[(i*cinfo.image_width*3)+(j*3)+0]; // Red Pixel
   raw_image[(i*cinfo.image_width*3)+(j*3)+1]; // Green Pixel
   raw_image[(i*cinfo.image_width*3)+(j*3)+2]; // Blue Pixel
   // Now you have pixel (i,j). You can do any thing with this.
 }
}

```
